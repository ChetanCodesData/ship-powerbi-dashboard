# 📦 Logistics & Shipment Analytics Dashboard

## 📌 Project Overview

This project is an end-to-end Logistics and Shipment Analytics Dashboard built using Power BI, PostgreSQL, SQL, and DAX.

The goal of this project is to analyze shipment operations, monitor delivery performance, track freight costs, identify damaged shipments, and generate business insights through interactive dashboards.

---

# 🚀 Key Objectives

* Analyze shipment and delivery performance
* Track freight and transportation costs
* Identify delayed and damaged shipments
* Compare carrier efficiency
* Build interactive KPI dashboards
* Generate business insights for logistics optimization

---

# 🛠 Tech Stack

* Power BI
* PostgreSQL
* SQL
* Data Visualization

---

# 📊 Dashboard Features

## ✅ KPI Cards

* Total Shipments
* Total Freight Cost
* Average Delivery Days
* On-Time Delivery %
* Damage %
* Average Cost Per KG
